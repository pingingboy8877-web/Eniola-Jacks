## ✦ THE IDEA

> This is not a conventional actor portfolio.

It is designed as a **cinematic digital stage** — a site where typography, portraiture, motion, pacing and interaction behave like part of a film sequence.

The interface deliberately avoids numbered section labels and generic template patterns.

### EXPERIENCE

```
PORTRAIT REEL        → moving cinematic image sequence
TEXT CHOREOGRAPHY    → independent fade / rise reveals
ROLE EXPLORATION     → interactive work cards
NEXT STORY           → instant role-to-role transition
EDITORIAL PRESS      → magazine-style press archive
INDUSTRY STRIP       → moving platform / broadcaster names
CUSTOM CURSOR        → desktop pointer choreography
MOBILE MENU          → clip-path cinematic transition
```

---

## ◌ VISUAL SYSTEM

| Layer | Direction |
| --- | --- |
| **Atmosphere** | Deep plum / cinematic pink / soft white |
| **Typography** | Manrope + DM Mono |
| **Motion** | Slow, deliberate, film-like |
| **Images** | Editorial portrait treatment |
| **Navigation** | Minimal desktop + cinematic mobile overlay |
| **Interaction** | Magnetic controls, hover movement, modal transitions |
| **Accessibility** | Reduced-motion fallback + touch-safe behavior |

The visual language is intentionally **dark, elegant and editorial** rather than a standard black/white portfolio.

## 🎞 INTERACTION MAP

**01 — ARRIVAL**

A full-screen loader establishes the identity before the interface enters.

**02 — HERO**

ENIOLA JACK arrives through staggered typography while the portrait reel moves continuously through the composition.

**03 — INDUSTRY**

A horizontal industry strip passes through the page with platform and broadcaster names.

**04 — THE PRACTICE**

Large statement typography appears progressively instead of arriving as one block.

**05 — WORK**

Roles are interactive. Selecting a role opens a cinematic panel rather than navigating away.

**06 — NEXT STORY**

Inside a role, the viewer can move directly into the next story.

**07 — PRESS**

Editorial-style entries simulate a press archive. Demo stories are explicitly marked as fictional and are not presented as real coverage.

**08 — CONTACT**

The experience closes with a direct contact moment rather than a conventional form-heavy footer.

## ⚡ FRONTEND

Built with:

- React
- Vite
- CSS animations
- CSS transforms
- Intersection-based reveal choreography
- Responsive layouts
- Reduced-motion support

Performance-sensitive animation stays in the browser. The API is intentionally lightweight and does **not** sit in the animation path.

### Run locally

```bash
npm install
npm run dev
```

### Production build

```bash
npm run build
npm run preview
```

---

## 🐍 LIGHTWEIGHT API

The `backend/` directory contains a small FastAPI service for future server-side functionality.

### Endpoints

```
GET  /api/health
GET  /api/site
POST /api/contact
```

Run it locally:

```bash
cd backend
pip install -r requirements.txt
uvicorn app:app --reload
```

## ✦ CONTENT NOTE

The work titles, press stories, dates and contact placeholders in this repository are **portfolio/demo content unless replaced with verified information**.

The Press section intentionally uses fictional editorial concepts and labels them **FICTIONAL DEMO** so the site does not falsely claim real coverage.

Replace them with verified credits, interviews, publications, representation and contact details before production use.
